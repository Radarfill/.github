# RadarFill

**Seeing crops through the clouds.** Radar fills cloud gaps in satellite greenness curves, using past data only, so crops can be recognised weeks earlier, with confidence you can trust.

Final-year research project, Faculty of Information Technology, University of Moratuwa (2026–2027).

| Track | Focus |
|---|---|
| A | Past-only radar-guided gap filling with calibrated uncertainty |
| B | Early crop recognition: fill vs fuse, earliest reliable date |
| C | Gap-aware trust: calibration and conformal prediction sets |

Main repository: [radarfill/radarfill](https://github.com/radarfill/radarfill)
